# Integrations

Adapters bind pyverge convergence to a framework boundary.

- [FastMCP](fastmcp/index.md) — versioned tools, prompts, and resources over MCP.
- [FastStream](faststream/index.md) — subscriber and publisher convergence over a message broker.
- [Celery](celery/index.md) — task payload and return convergence, including multi-version chains.
- [httpx](httpx/index.md) — request and response convergence through an `httpx` transport.
