# CI Gate

A minimal project showing how to run pyverge in CI.

## Files

- `models.py` — one versioned `User` graph and a forward migration
- `payloads/user_v1.json` — a payload that must converge
- `.github/workflows/pyverge.yml` — CI gate

## Run locally

```bash
cd showcases/ci
pip install "pyverge[cli]"

pyverge doctor --manager models:manager
pyverge manifest --manager models:manager --output target/pyverge-manifest.json
pyverge compat --manager models:manager --fail-on-breaking
pyverge migrate payloads/user_v1.json --manager models:manager --check
```

## CI checks

- `doctor` fails on missing model references or migration gaps
- `manifest` uploads a JGF v2 graph snapshot as a CI artifact
- `compat --fail-on-breaking` exits `3` on breaking schema changes
- `migrate --check` fails when a sample payload cannot converge

The manifest is generated by the CLI only. The application lifespan does not
write it.

To reuse the workflow in an application repo, copy
`.github/workflows/pyverge.yml` to the repository root and remove
`defaults.run.working-directory`.

Compare manifests across branches by downloading the artifact from the base
branch and running a JSON diff against the current one.
